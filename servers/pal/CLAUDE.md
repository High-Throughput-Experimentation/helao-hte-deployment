# PAL driver

The SSH tuple for a remote PAL controller (`user`, `key`, `host`) is read by `pal_driver._env_param`. Configs name environment variables instead of holding the values (`user_env`, `key_env`, `host_env`, as in `password_env` of the synaccess driver), so the public repo and `/get_config` carry only the variable names. Set HELAO_PAL_SSH_USER, HELAO_PAL_SSH_KEY and HELAO_PAL_SSH_HOST per station as persistent user env vars (Windows: `setx NAME value`, then open a new terminal; Linux: shell profile). A literal `user`/`key`/`host` param still wins. An unset `host_env` variable logs an ERROR at startup and `sshhost` stays `None`: `connect()` fails and every PAL action returns `not_available` (fails closed; local mode is only `host: localhost`).
